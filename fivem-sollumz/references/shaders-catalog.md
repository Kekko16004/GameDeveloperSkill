# Catalogo shader GTA V (Sollumz 2.9 / szio Shaders.xml)

Generato dai dati di Sollumz (`szio/gta5/Shaders.xml`, 249 shader base, 296 preset). Nome da passare a
`sz.material(obj, "<preset>", ...)` = colonna **preset** (con o senza `.sps`).

## Scelta rapida per prop

| Hai... | Shader | Note |
|---|---|---|
| solo diffuse | `default` | il piu' economico; supporta UV anim |
| diffuse + normal | `normal` | supporta UV anim |
| diffuse + specular | `spec` | supporta UV anim |
| diffuse + normal + specular | `normal_spec` | standard per prop di qualita'. **NON supporta UV anim** |
| ritagli (foglie, griglie, recinzioni) | `cutout`, `normal_spec_cutout`, `cutout_fence` | alpha 0/1, ordinamento ok, ombre corrette |
| trasparenza vera (plastica, vetro sporco) | `alpha`, `normal_spec_alpha`, `glass`, `glass_env`, `glass_spec` | bucket alpha: evita sovrapposizioni, valuta flag Draw Last |
| decalcomanie su altra geometria | `decal`, `normal_spec_decal`, `decal_dirt` | geometria leggermente sollevata (1-2 mm) |
| luce propria (insegne, schermi, LED) | `emissive`, `emissivestrong`, `emissive_alpha`, `emissivenight` (solo di notte), `normal_spec_emissive` | parametro `emissiveMultiplier` |
| varianti colore via script | `default_tnt`, `normal_tnt`, `normal_spec_tnt`, `*_cutout_tnt`, `emissive_tnt` | TintPaletteSampler + `SetObjectTextureVariation` |
| riflessi | `normal_spec_reflect`, `reflect`, `glass_reflect`, `normal_spec_cubemap_reflect` | EnvironmentSampler |
| specchio | `mirror_default` | serve setup MLO/portal mirror |
| rilievo parallax | `normal_spec_pxm`, `parallax` | heightSampler |
| texture di dettaglio tiling | `normal_spec_detail`, `default_detail` | DetailSampler |
| schermo DUI | `emissive` / `default` con texture in **YTD esterno** | vedi recipe-dui.md |

Shader che supportano **UV animation** (globalAnimUV0/1):
`alpha, cutout, default, default_noedge, default_terrain_wet, emissive, emissive_additive_uv_alpha, emissive_alpha,
emissive_clip, emissivestrong, emissivestrong_alpha, glass_emissive, glass_emissive_alpha, glass_env, gta_default,
gta_normal, gta_spec, normal, normal_alpha, normal_cutout, normal_decal, normal_decal_pxm, normal_pxm,
normal_screendooralpha, normal_spec_decal, normal_spec_decal_pxm, normal_terrain_wet, ptfx_model, spec, spec_alpha,
spec_screendooralpha, water_decal, weapon_emissivestrong_alpha`.

Bucket: `opaque` (0), `alpha` (1), `decal` (2), `cutout` (3), `nomotionblur` (4), `water` (5).
